## Как удалось войти в игру

Путь: `LauncherActivity` → «Open game» → оригинальный сега-титул/обучение (тапы по меню) → миссионная презентация → Ментат → карта кампании → `GAMEPLAY / TACTICAL`.

Ключевые строки диагностического журнала (фрагмент):

```text
2026-11-18 16:41:22.705 [MODE] CAMPAIGN_MAP -> GAMEPLAY phase=TACTICAL
2026-11-18 16:42:11.528 [FRAME_JANK] interval_ms=66.67 mode=GAMEPLAY phase=TACTICAL render_tick=2663
```

## Геометрия трёх кнопок HUD в кадре

Диагностический лог отрисовки (координаты View; для нажатий на экран надо добавить +128 к X):

```text
DuneHudDebug: drawButton RectF(1944.0, 655.7037, 2019.8518, 731.55554)   // левая
DuneHudDebug: drawButton RectF(2034.0741, 655.7037, 2109.926, 731.55554) // средняя
DuneHudDebug: drawButton RectF(2124.1482, 655.7037, 2200.0, 731.55554)   // правая
```

Три кнопки одинакового размера 75.85×75.85 px, зазоры 14.22 px, один ровный ряд над радаром, правый край совпадает с правым краем радара. Радар и кнопки рисуются в каждом игровом кадре.
