# Состояние отладки: вылет при запуске РОМ

## Что сообщил пользователь
Приложение открывается, но **в самом начале не запускает РОМ и падает с ошибкой**. Текст ошибки с экрана пока не прислан.

## Что уже проверено
- APK `DemulationMod_HUD_Sega_v2.apk` подписан, устанавливается и запускается до лаунчера на эмуляторе Android 14.
- При запуске лаунчера и случайных касаниях (`monkey`, 400 событий) `FATAL EXCEPTION` не пойман.
- Напрямую стартовать `MainActivity` нельзя: активность не экспортирована, система возвращает `Permission Denial`.
- Эмулятор периодически показывает системные окна `System UI isn't responding`. Они мешают автоматическому переходу в игру, но относятся к системе, а не к нашему APK.
- Шрифт `dune_sega.ttf` исправен: 576 глифов, есть цифры и кириллица.
- Проверка подписи `apksigner verify` проходит. Хеш APK совпадает на GitHub и файлообменнике.

## Что может вызывать вылет
1. Файл шрифта `assets/fonts/dune_sega.ttf`. Fallback есть, но на реальном устройстве возможна ошибка загрузки Typeface.
2. Правка `activeViewportRect` на 24 пикселя со всех сторон. Это может влиять на инициализацию игры и нативный рендер.
3. Дополнительный файл `classes3.dex` с хелпером `DuneSegaHud`. На некоторых устройствах multidex может работать иначе.
4. Правки хитбокса и оверлеев кнопки базы. Маловероятно, но проверяется.

## План дальнейших действий
1. Поймать `logcat` именно при запуске РОМ: очистить журнал, открыть лаунчер, перейти в игру.
2. Если вылет Java — исправить конкретный стек.
3. Если вылет связан со шрифтом — собрать вариант без внешнего TTF, только со встроенным моноширинным шрифтом.
4. Если вылет связан с `classes3.dex` — перенести методы хелпера прямо в `classes2.dex` и убрать третий dex.
5. Если вылет связан с отступом карты — вернуть `activeViewportRect` к исходному значению, а отступы оставить только у радара и HUD.
6. После исправления собрать новую версию, проверить её, выпустить новый GitHub Release и новую временную ссылку на файлообменнике.
